# X（旧Twitter）投稿テンプレート

`{{中間ページURL}}` はブログのハブ or レビューURL。  
原則 **アフィ直リンクを連投しない**（プロフ or 記事経由）。

---

## 型A: 問題提起

```
初めて{{ニッチ}}を選ぶとき、
失敗しやすいのって「{{よくある失敗}}」なんですよね。

回避の手順とおすすめの見方をまとめました。
▼ {{中間ページURL}}
```

---

## 型B: 結論1行

```
結論: 初めてなら {{推し商品のぼかした呼び方}} が無難。

理由は3つだけ記事に書いてます。
{{中間ページURL}}
```

---

## 型C: 比較

```
{{A}}と{{B}}、どっちから見る？

・{{A}}: {{向いてる人}}
・{{B}}: {{向いてる人}}

表で並べた → {{中間ページURL}}
```

## 型D: チェックリスト

```
{{ニッチ}}を選ぶ前の3チェック

{{中間ページURL}}
```

## 型E: 更新・追記告知

```

{{中間ページURL}}
```

```

失敗しない1本の基準をまとめてます
▼まとめ
{{中間ページURL}}
```

## 固定ポスト

```

比較表 + 注意点 + おすすめ順
{{中間ページURL}}

```
