# コンプライアンス & 運用ルール（アダアフィ）

法律の助言ではありません。**公式の参加規約・各プラットフォーム規約が常に優先**です。  
作業前に一度チェックし、怪しい表現は使わない。

---

## 年齢

- [ ] 取り扱う内容が成人向けであることを理解している
- [ ] サイト上で成人向けである旨・年齢に関する注意を出せる
- [ ] 未成年向けに見せない（表現・導線・広告設定）
- [ ] 利用する SNS / 動画媒体の年齢制限ポリシーを確認した

---

## 規約（DMMアフィリエイト）

登録時に公式の利用規約・掲載基準を保存すること。

- [ ] https://affiliate.dmm.com/ の規約・ガイドを確認
- [ ] https://support.dmm.com/affiliate のルール系記事を確認
- [ ] 禁止される誘導（虚偽・不正クリック強要など）をしない
- [ ] サイト内容と申請内容が一致している
- [ ] 知的財産権を侵害するコンテンツを置いていない

**不承認で多いパターン（再確認）**

- 非公開サイト
- 中身のないサイト
- 内容不一致
- 権利侵害

---

## 画像・動画・テキスト

- [ ] 公式が許可する範囲の素材か、自作・正当な引用か確認した
- [ ] 他サイトからの無断転載をしていない
- [ ] 作品本編の無断アップロード・配布をしていない
- [ ] サンプル・スクショ利用は各サービスの規定に従う
- [ ] 過度な性的表現が掲載先メディアの規約に抵触しないか確認した

---

## 表現・景表法・誇大

- [ ] 「必ず稼げる」「絶対に満足」など断定的な根拠なき表現を使っていない
- [ ] 体験談は事実に基づく（未体験を体験と偽らない）
- [ ] 価格・キャンペーン情報は古くなったら更新 or 日付を明記
- [ ] アフィリエイトリンクを含むことを読者が分かるよう表記した

---

## プラットフォーム別メモ

| 媒体 | 確認すること |
|------|----------------|
| 自サイト | 年齢注意、アフィ表記、権利 |
| X | 成人コンテンツ・スパム・外部リンク方針 |
| YouTube | 年齢制限、広告適合、概要欄リンク |
| その他SNS | コミュニティガイドライン全文 |

- [ ] 使う媒体すべての規約を一度開いて確認した

---

## 個人情報・税務（運用が乗ってきたら）

- [ ] 報酬の受取口座は本人名義など公式要件を満たす
- [ ] 一定以上の所得は税務上の申告が必要になり得る（税理士・公式情報で確認）
- [ ] パスワードを使い回していない
