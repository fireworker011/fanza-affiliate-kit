# 山口式ナレッジ（note特化アフィリエイト・プロジェクト）

「AI山口くん」商品紹介ページ生成インストラクションのナレッジ置き場。

| ファイル | 内容 | 用途 |
|---|---|---|
| [`instruction_full.md`](instruction_full.md) | インストラクション原文（2026-08-26 受領版・無編集） | AI（Claude / Cursor / Grok Bot）に読み込ませる原本。**このプロジェクトで参照するのはこのファイルのみでよい** |
| [`note_article.md`](note_article.md) | 原文のエッセンスを note 発信用にまとめた記事ドラフト | note にコピペして投稿（公開前に自分の言葉・体験を追記すること） |

## 運用メモ

- 原文は編集しない。手法をアップデートしたら新しい版を別ファイルとして追加し、この表に行を足す。
- note へ投稿する際は、記事内でも触れているとおり **#PR 表記・薬機法/景表法の遵守・体験談の捏造禁止** を必ず守る（`checklists/compliance.md` も参照）。
- 実際の商品紹介ページ生成は、`instruction_full.md` をそのままAIのシステムプロンプト/ナレッジとして与え、ステップ1から対話で進める。
