## 原因ランキング（重要度順）

### 1. サイトが検索エンジンに「載るな」と言っていた（致命・技術）

全HTMLに:

```html
<meta name="robots" content="noindex,nofollow" />
```

が付いていた。Google等は原則インデックスしない。  
→ note以外の自動流入が **構造的に不可能** だった。

**対策（実施）:** noindex削除 / robots.txt / sitemap.xml 追加。

### 2. 流入源が「新規note 1本」だけ（致命・集客）

- アカウント新規・フォロワーほぼゼロ想定
- 公開2日・スキ数はごく少数
- Xは使わない方針
- 検索も上記noindexで封じられていた

→ **誰もリンクに到達しない** のが正常な結果。  
商品やレビュー品質の問題より前に「人の目が無い」。

**対策（実施）:** note連載パック（短文複数）+ 7日運用表 + プロフィール文。

### 3. 報酬＝クリックではなく「クリック後の購入」

仮にハブに来ても、成約までには距離がある。  
今の0は成約以前の **到達0** が主因。

### 4. 中間ページの摩擦（中・改善済み/継続）

- 年齢ゲート: 必要。1回同意後はlocalStorageでスキップ
- CTAは複数あるが、スマホではさらに固定バーがあると押しやすい  
  → sticky CTA を追加

### 5. 計測の見え方

- DMMレポートの「クリック」はアフィリンク踏んだ数
- noteの閲覧数 ≠ アフィクリック
- ハブPVを見る仕組みは無い（静的サイト）  
  → まずは note閲覧 → ハブ到達 → DMMクリック の順で見る
