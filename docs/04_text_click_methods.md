# 04 文章でアフィリンクを踏ませる方法

ブログ・記事・固定ページ向け。  
ゴールは「読者が迷わず **1回は** 公式商品ページを開く」こと。

---

## 配置ルール

最低 **3箇所**（テンプレの CTA-1 / CTA-2 / CTA-3 と対応）。

| 位置 | タイミング | 役割 |
|------|------------|------|
| **CTA-1 冒頭** | 結論の直後 | すでに決めてる人を逃さない |
| **CTA-2 中盤** | メリット or 比較表の直後 | 納得した瞬間に押させる |
| **CTA-3 結論** | まとめの直前〜直後 | 読み切った人の最後の一押し |

### 追加で効く位置

- 比較表の「推し」行の右端
- 「向いている人」リストの直後
- 記事目次の下（長い記事）

### やってはいけない配置

- 記事と無関係な位置にだけリンク
- 本文ゼロでリンクだけ
- 同じページに異なる商品を等間隔で押しすぎて結論が消える
- 誇大・虚偽（「必ず稼げる」「絶対満足」等）

---

## CTA文言パターン

`{{AFFILIATE_LINK}}` を実リンクに置換して使う。

### 基本セット（無難）

```markdown
👉 [公式で作品詳細・サンプルを確認する]({{AFFILIATE_LINK}})
```

```markdown
【チェック】[FANZAで内容を見る]({{AFFILIATE_LINK}})
```

### 初心者・登録誘導

```markdown
まずは公式の案内を確認 → [詳細はこちら]({{AFFILIATE_LINK}})
```

```markdown
手順どおり進めるなら → [公式ページを開く]({{AFFILIATE_LINK}})
```

### 比較・ランキング後

```markdown
結論の1本はこちら → [おすすめ作品をFANZAで見る]({{AFFILIATE_LINK}})
```

```markdown
表で比較したうえで決めるなら → [推しの商品ページ]({{AFFILIATE_LINK}})
```

### レビュー締め

```markdown
気になったらサンプルだけでもOK → [公式サンプル・詳細]({{AFFILIATE_LINK}})
```

```markdown
「自分向きか」は公式情報と合わせて判断 → [商品ページへ]({{AFFILIATE_LINK}})
```

### ボタン風HTML（サイトがHTML可の場合）

```html
<p style="text-align:center;margin:1.5em 0;">
  <a href="{{AFFILIATE_LINK}}" rel="nofollow sponsored"
     style="display:inline-block;padding:12px 24px;background:#e60012;color:#fff;text-decoration:none;border-radius:6px;font-weight:bold;">
    公式で詳細を確認する
  </a>
</p>
```

> `rel` の付け方はサイト方針とプラットフォーム推奨に合わせる（例: nofollow / sponsored）。

## クリック率を上げる文章テク（合法・誠実）

1. **先に結論** … 「結論から言うと〇〇」→ CTA-1
2. **具体性** … 抽象称賛より「尺・形式・向いてる人」
3. **一つに絞る** … 3選でも「初めてならA」
4. **不安の先回り** … 料金・対応端末・解約/単品の違いを短く
5. **次アクションを動詞で** … 「確認する」「サンプルを見る」「詳細を開く」
6. **リンクテキストを「ここ」にしない** … 何が起きるか書く

### 前後の接続例

```markdown
総合すると、初めてなら A が無難です。
理由は「〇〇」と「△△」のバランスが良いからです。

<!-- CTA-2 -->
👉 [Aの公式ページで詳細を確認する]({{AFFILIATE_LINK}})

なお B はこういう人向けです……
```

## 記事タイプ別の押し方

### 個別レビュー

- 推しポイント3つの直後に CTA-2
- 向かない人を書いた **後** に CTA-3（誠実さがクリックに効く）

### ランキング

- 1位の直後に強CTA
- 2位・3位は弱めのテキストリンク
- 記事末で再度1位を推す

### 初心者ガイド

- 「登録/購入の流れ」ステップの各所に公式リンク
- 新規紹介を意識し、手順の正確さを優先（誇張しない）
