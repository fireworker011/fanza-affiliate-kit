# 03 環境構築 & アフィリエイトリンク獲得

アダアフィ（FANZA / DMMアフィリエイト）に必要な **アカウント・媒体・ツール・リンク作成** を一箇所にまとめたガイドです。

> 公式画面は更新されることがあります。ボタン名が違う場合は管理画面の「広告リンク作成」「ヘルプ」を優先してください。  
> 公式: https://affiliate.dmm.com/ / ヘルプ: https://support.dmm.com/affiliate

---

## 必要アカウント

| # | アカウント | 必須度 | 用途 | メモ |
|---|------------|--------|------|------|
| 1 | メールアドレス | 必須 | 登録・審査連絡 | アフィ専用推奨 |
| 2 | DMM 会員 | 必須 | アフィリエイト利用の土台 | https://www.dmm.com/ 等 |
| 3 | DMMアフィリエイト | 必須 | リンク発行・報酬 | https://affiliate.dmm.com/ |
| 4 | ブログ/サイト | 強く推奨 | 中間LP・審査・SEO | WordPress 推奨 |
| 5 | X（旧Twitter） | 推奨 | 入口集客 | プロフィールに中間URL |
| 6 | 銀行口座 or DMMポイント受取設定 | 必須（受取時） | 報酬受取 | 支払下限あり（公式ヘルプ） |
| 7 | YouTube 等 | 任意 | 動画導線 | 直リンクより概要欄→中間ページ |

### セットアップ順序

1. メール作成
2. DMM 会員登録
3. **ブログを最低2記事公開**（審査対策）
4. https://affiliate.dmm.com/ でアフィリエイト開始
5. サイトURLを申請
6. 承認後にリンク作成
7. 報酬受取方法を設定

### Done when

- [ ] 上記1〜3が使える
- [ ] アフィリエイト管理画面に入れる（申請後）
- [ ] 受取方法の設定場所を確認した

## 媒体準備

### A. ブログ（本命）

**推奨構成**

```
/                     トップ（何の専門サイトか）
/privacy/             プライバシー
/contact/             問い合わせ
/affiliate-disclosure/ アフィリエイト表記（任意だが推奨）
/guide-xxx/           ハブ記事
/review-a/            レビュー
/review-b/            レビュー
```

**最低限の表示**

- サイト名・運営者の識別（匿名でも「お問い合わせ可能」）
- 成人向けコンテンツがある場合の注意
- 「本ページにはアフィリエイトリンクを含みます」等の表記

**WordPress を使う場合の最低プラグイン（任意）**

- キャッシュ / SEO 基本（All in One SEO 等）は好みで
- リンク管理: Pretty Links 等で短縮・クリック計測（任意）
- バックアップ

**無料ブログ注意**

- サービス終了・広告制限・アダルト禁止規約に注意
- 本気運用なら独自ドメイン + WordPress が無難

### B. X（入口）

プロフィール例（プレースホルダ）:

```
{{ニッチ}}の選び方・レビュー
失敗しない1本をまとめてます
▼まとめ
{{中間ページURL}}
```

固定ポスト: ハブ記事 or「初めての方向け」へのリンク。

### C. 動画媒体

- 動画内に長いアフィURLを連呼しない
- **概要欄 → 中間記事 → アフィリンク**
- プラットフォームのアダルト・外部リンク規約を必ず確認

### Done when

- [ ] 公開URLで記事が読める
- [ ] プロフィール or トップに専門性が書いてある
- [ ] アフィリエイト表記の文面を用意した

## アフィリエイトリンク獲得

DMMアフィリエイトでは公式に複数の作成手段があります  
（出典の入口: https://affiliate.dmm.com/guide/diagram/ad ）。

| 手段 | 向いている場面 | 公式の位置づけ |
|------|----------------|----------------|
| **アフィリエイトツールバー** | PCで商品ページを見ながら即リンク | https://affiliate.dmm.com/guide/diagram/toolbar |
| **商品リンク作成** | URLが分かっている・スマホ | 管理画面「広告リンク作成」系 |
| **キーワードリンク** | 検索結果・キーワード誘導 | 広告作成ツール群 |
| **バナー素材集** | 画像付き広告枠 | 同上 |
| **ウィジェット** | サイト埋め込み型 | 同上 |

### 方法1: アフィリエイトツールバー（PC推奨）

1. DMMアフィリエイトに **ログインした状態** でブラウザを使う
2. FANZA / DMM の **紹介したい商品ページ** を開く
3. ページ上部の **アフィリエイトツールバー** が表示されることを確認  
   - 出ていない → ログイン状態・非表示トグル・対象外ページの可能性
4. **リンクを作成** を押す
5. 表示されたリンクから **URLリンクをコピー**（またはHTMLをコピー）
6. 記事の `{{AFFILIATE_LINK}}` に貼る

**うまくいかないとき**

- 「アフィリエイト対象外」→ その商品/ページはリンク不可。別商品を選ぶ  
  （ヘルプ例: https://support.dmm.com/affiliate/article/47543 ）
- ツールバーが出ない → ログアウトしていないか、別ブラウザプロファイルでないか確認
- スマホではツールバーが使いにくい → 方法2へ

### 方法2: 商品リンク作成（管理画面）

1. https://affiliate.dmm.com/ にログイン
2. メニューから **広告リンク作成 → 商品リンク作成**（名称は画面に従う）
3. 入力
   - アフィリエイトID（サイトに対応するID）
   - リンクページURL（FANZA商品ページのURL）
   - 商品名（任意）
4. **リンクを作成 / HTMLソースを作成**
5. 生成された **リンクURL** をコピー
6. X 連携ボタンがある場合は、投稿下書きに使える（規約に注意）

### 方法3: バナー / キーワードリンク

1. 管理画面のバナー素材集 or キーワードリンク作成を開く
2. サイズ・ジャンルを選ぶ
3. HTMLをコピーして記事の広告枠に貼る
4. テキストサイトではバナーより **テキストCTA + 商品リンク** の方が読みやすいことが多い

### リンク設置ルール（運用）

1. 1記事の主推しみは **1商品（または1サービス）** をメインにする
2. 同じリンクを冒頭・中盤・結論に置く（詳細は `docs/04`）
3. 短縮URLを使う場合
   - 自サイト経由（Pretty Links 等）が管理しやすい
   - 第三者短縮サービスの消滅リスクに注意
4. リンクの動作確認: シークレットウィンドウで踏んで商品ページに着地するか見る
5. 自己購入の成果可否は **公式ヘルプの最新回答** を確認（自己購入前提の運用は非推奨）

### Done when

- [ ] ツールバーまたは商品リンク作成で実リンクを1本取得した
- [ ] 記事に貼り、クリックで商品ページに着地した
- [ ] 対象外ページで詰まったときの代替手順を知っている

## 登録・審査の実務

### 申請時に入れる情報（典型）

- アフィリエイトID（**後から変更できない** ことが多い → 慎重に）
- 運営サイト名
- 運営サイトURL
- SNSのみの場合はアカウントURL（審査はブログより厳しい場合あり）

### 不承認で多い理由（公開情報ベース）

1. サイトがWeb公開されていない
2. 初回登録時の状態で内容が確認できない（中身なし）
3. サイト内容がアフィリエイトとマッチしない
4. 知的財産権の侵害

**対策:** レビュー記事を2本以上公開してから申請。画像は公式が許可する範囲・自己責任で権利確認。

### 報酬・支払い（概要）

- 料率・キャンペーンは変動 → https://affiliate.dmm.com/fee/rate/ を都度確認
- 支払タイミング・下限額は公式ヘルプ（例: 月末締め・翌月振込、下限あり等）
- ダイレクト / カテゴリ / 新規紹介など複数チャンスがあるのが特徴

## 年齢・コンプライアンス（運用上の最低ライン）

詳細は `checklists/compliance.md`。ここでは環境面のみ。

- 成人向けを扱う媒体では **18禁であることの明示** と、プラットフォーム年齢制限の遵守
- 一般向けSNSではアダルト表現・サムネが即BANになり得る → **中間ページ誘導** を基本に
- 公式の参加規約・禁止事項を登録時に保存（PDF/スクショ）
- 他社画像・サンプルの無断転載をしない。アフィリエイト用に許諾された素材・引用ルールを守る
