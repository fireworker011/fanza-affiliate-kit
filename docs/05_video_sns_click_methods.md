# 05 動画・SNSでアフィリンクを踏ませる方法

入口（動画/SNS）→ **中間ページ（ブログ）** → アフィリンク、が基本形です。  
直リンク連投は媒体BAN・信頼低下のリスクが高いので推奨しません。

---

## 全体導線

```
[動画 or SNS投稿]  興味づけ・問題提起・一言レビュー
        ↓ プロフィール / 概要欄 / 固定コメント
[中間ページ]  ハブ or レビュー（信頼・比較・CTA×3）
        ↓ affiliate link
[FANZA 商品ページ]
```

### なぜ中間を挟むか

1. 媒体のアダルト・スパム規約を守りやすい
2. 複数商品・カテゴリ回遊で報酬機会が増える
3. リンク変更時に中間だけ直せばよい
4. SEO資産が残る

## SNS導線

### X（旧Twitter）— 主戦場になりやすい

**プロフィール**

```
{{ニッチ}}レビュー / 失敗しない選び方
詳細まとめ ▼
{{中間ページURL}}
```

**投稿の型（1日1〜3本）**

| 型 | 内容 | 誘導先 |
|----|------|--------|
| 問題提起 | 「初めてで失敗しがちなポイント」 | ハブ記事 |
| 一言感想 | 作品の「向いてる人」だけ | 個別レビュー |
| 比較 | AとBの違いを3行 | ランキング記事 |
| セール/時期 | 事実ベースの告知 | ハブ or 商品中間 |

**投稿末尾の誘導例**

```
詳細と選び方はプロフィールのまとめから
```

```
比較表はこちら（ブログ）→ {{中間ページURL}}
```

**避けること**

- アフィURLの連投だけ
- 煽り・虚偽の実績
- 規約違反のサムネ・文言（各SNSの成人コンテンツ規定）
- 他アカウントへの無差別リプライ営業

詳細文例: `templates/x_post_templates.md`

### その他SNS

| 媒体 | 現実的な使い方 |
|------|----------------|
| Instagram | 規制が強い。外部はストーリーズ/プロフ経由が無難 |
| TikTok | 動画内直リンク不可が多い → プロフ or 別媒体 |
| YouTube | 概要欄に中間URL。成人向けはアカウント/広告制限に注意 |
| Discord等 | コミュニティ規約を確認のうえ、レビュー要約+URL |

## 動画導線

### 構成テンプレ（60〜180秒ショート想定）

1. **0〜3秒** フック（「初めて選ぶとき見るのはここ」）
2. **本編** ポイント3つ（映像は規約内・非アダルト表現で）
3. **締め** 「詳細は概要欄の記事に比較表あります」
4. **概要欄**
   ```
   まとめ記事（比較・注意点）:
   {{中間ページURL}}

   ※記事内にアフィリエイトリンクを含みます
   ```

### 長尺（5〜10分）の場合

- 章ごとに「詳しくは記事の〇節」
- 固定コメントに中間URL
- 動画説明の最上行にURL

### 動画でやってはいけないこと

- 権利のない本編映像の無断使用
- プラットフォームが禁止する露骨な成人表現
- 概要欄に短縮アフィを並べるだけのスパム

### 既存のショート工場について

`fanza_shorts_factory/` がある場合でも、**アダルト本編の自動生成・無断素材** は本キットの対象外です。  
動画を使うなら「規約内のトーク・画面録画解説・テキスト動画」など、媒体が許容する形式に限定してください。

## クリックを増やす運用ルール

### 週次ルーチン

| 曜日イメージ | やること |
|--------------|----------|
| 毎日 | 入口投稿1本（型をローテ） |
| 週2 | ブログ更新 or 加筆（CTA改善） |
| 週1 | DMMレポートでクリック有無を確認 |
| 月1 | ニッチ内の推し商品を見直し |

### ABの考え方（簡易）

同じ中間URLに対し、投稿のフックだけ変える。

- A: 失敗談フック
- B: 比較フック  
反応が良い型を残す。

### 指標

| 指標 | 見る場所 | 悪いときの打ち手 |
|------|----------|------------------|
| インプレッション | SNS分析 | フック・投稿時間 |
| プロフクリック | SNS分析 | プロフ文・固定 |
| 記事PV | ブログ解析 | タイトル・導入 |
| アフィクリック | DMMレポート / 自前短縮 | CTA文言・位置 |
| 成果 | DMMレポート | 商品選定・初心者向け手順 |

## コピー用：動画概要欄テンプレ

```
【今日のまとめ】
{{一言結論}}

▼選び方・比較表（記事）
{{中間ページURL}}

※本記事・本チャンネルの紹介にはアフィリエイトリンクが含まれる場合があります。
※年齢制限・各サービスの利用規約を守って利用してください。
```

## コピー用：固定コメント

```
比較と注意点はこちら → {{中間ページURL}}
```
