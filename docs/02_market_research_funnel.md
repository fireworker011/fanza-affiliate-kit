## 稼ぎ直結コンテンツマップ

成約しやすい構造はこれだけ覚える。

```
[入口] 検索 or SNS投稿
        ↓
[ハブ] 比較 / ランキング / 初心者ガイド
        ↓ 内部リンク
[レビュー] 個別作品・サービス詳細
        ↓ affiliate CTA ×3
[FANZA/DMM 商品ページ] 購入 or 登録
```

ASCII でもう一段具体化:

```
X投稿「〇〇で失敗しない選び方」
  └→ ハブ記事（結論1本 + 3選比較）
        ├→ レビューA ──CTA──→ 商品Aアフィリンク
        ├→ レビューB ──CTA──→ 商品Bアフィリンク
        └→ レビューC ──CTA──→ 商品Cアフィリンク
              （ハブ自身にも CTA = 推し商品）
```

### 初回キャンペーンの最小セット

| # | 役割 | テンプレ | 目的 |
|---|------|----------|------|
| 1 | ハブ | `templates/fanza_ranking_template.md` または `fanza_beginner_guide_template.md` | 流入の受け皿・比較・1本推し |
| 2 | レビュー | `templates/fanza_article_template.md` | 信頼・詳細・成約 |
| 3 | レビュー | 同上 | 回遊・カテゴリ報酬も狙う |

### ハブ記事の必須要素

1. 結論（推し1本）を **冒頭** で出す
2. 比較表（3列まで）
3. 各候補への内部リンク
4. **affiliate CTA** を冒頭・中盤・結論の3回
5. 注意点（料金・年齢・環境）を1ブロック

### レビュー記事の必須要素

1. 誰向けか（ターゲット）
2. 作品/サービス概要（ネタバレ過多にしない）
3. 良い点3 / 気になる点2
4. こんな人におすすめ / 向かない人
5. **affiliate CTA** ×3
6. 関連（ハブへ戻る・姉妹レビューへ）

### 収益ロジック（設計時の意識）

| 報酬の型 | 導線での狙い方 |
|----------|----------------|
| ダイレクト | 個別レビューでその商品を強く推す |
| カテゴリ | 同ジャンルをハブでまとめ回遊させる |
| サービス新規 | 「初めての方向けガイド」で登録手順を丁寧に |
