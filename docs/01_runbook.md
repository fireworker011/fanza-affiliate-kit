## STEP 0 — 前提の理解（30分）

### やること

1. 報酬の種類を頭に入れる（詳細は公式料率ページで確認）
   - **ダイレクト報酬**: 紹介した同一商品が売れた
   - **カテゴリ報酬**: 同カテゴリの別商品が売れた
   - **サービス新規紹介**: そのサービスでの初回購入者など（高単価になりやすい）
2. 稼ぎやすい順序を理解する
   - 集客（検索 or SNS）→ 信頼ページ → アフィリンク → 購入/登録
3. このキットのゴールを確認する
   - 「初回キャンペーン」= ニッチ1つ + ハブ記事1 + レビュー2 + CTA設置 + 入口導線

### Done when

- [ ] 報酬3種の違いを自分の言葉で説明できる
- [ ] 「SNS直リンクだけ」より「中間ページ経由」が基本だと理解した

## STEP 1 — 市場リサーチ（ニッチ決定）

### やること

1. `docs/02_market_research_funnel.md` を開く
2. ニッチ候補を **3つ** 書き出す（例: 特定ジャンル動画 / 同人 / VR / 月額比較）
3. 需要チェック表を埋める（検索意図・競合の薄さ・自分が語れるか）
4. **1つだけ** 選ぶ（広げない）
5. 最初のキーワード3本を決める
   - ビッグ1: 例「FANZA 月額 おすすめ」
   - ミドル1: 例「〇〇 ジャンル おすすめ」
   - ロング1: 例「〇〇 作品 感想」

### Done when

- [ ] ニッチが1つに決まっている（紙 or メモに書いてある）
- [ ] キーワード3本が決まっている
- [ ] `checklists/first_campaign.md` の「市場リサーチ」欄が埋まっている

---

## STEP 2 — 環境構築（アカウント・媒体）

### やること

1. `docs/03_environment_and_links.md` の **必要アカウント** を上から用意する
   - メール（専用推奨）
   - DMM 会員
   - ブログ or 固定LP用サイト（推奨: WordPress / 最低: note 等は規約要確認）
   - X（旧Twitter）アカウント（入口用）
2. 媒体の最低構成を作る
   - トップ or プロフィールに「何の専門か」を明記
   - プライバシーポリシー / お問い合わせ / アフィリエイト表記の枠
   - 年齢確認・成人向けであることの注意（ブログ側）
3. `checklists/compliance.md` を一度通読し、運用ルールをメモする

### Done when

- [ ] DMM 会員にログインできる
- [ ] 公開可能な URL（ブログ or サイト）がある
- [ ] X プロフィール文と固定リンク枠が用意できている
- [ ] 規約チェックリストを1回読んだ

## STEP 3 — コンテンツ構造を先に作る（審査前）

> 審査は「空っぽのサイト」だと落ちやすい。**記事を先に2本以上** 用意してから申請する。

### やること

1. 稼ぎ直結マップに沿ってファイルを用意する（`docs/02` 参照）
   - **ハブ記事** 1本（比較・ランキング・初心者ガイド）
   - **レビュー記事** 2本（個別作品 or サービス）
2. テンプレをコピーして下書き
   - ハブ: `templates/fanza_ranking_template.md` または `fanza_beginner_guide_template.md`
   - レビュー: `templates/fanza_article_template.md`
3. 各記事に仮 CTA を3箇所入れる（リンクはまだプレースホルダでOK）
   - `{{AFFILIATE_LINK}}` のまま残す
4. サイトを **公開状態** にする（パスワード保護なし）

### Done when

- [ ] 公開URLで記事が2本以上読める
- [ ] 各記事に CTA-1 / CTA-2 / CTA-3 の位置がある
- [ ] サイトの趣旨（FANZA作品レビュー等）が第三者に伝わる

---

## STEP 4 — DMMアフィリエイト登録・サイト審査・リンク獲得

### やること

1. https://affiliate.dmm.com/ を開く（地域ブロック時は国内回線で再試行）
2. 無料会員登録 / アフィリエイト利用開始
3. サイト情報を登録
   - 運営サイト名
   - 運営サイトURL（STEP 3 で公開したURL）
   - アフィリエイトID（変更不可のため慎重に）
4. 審査結果メールを待つ（目安: 数時間〜数日。公式アナウンス優先）
5. 不承認時は公式に挙がる典型理由を潰して再申請
   - 非公開 / 中身なし / 内容不一致 / 権利侵害
6. 承認後、`docs/03_environment_and_links.md` の **アフィリエイトリンク獲得** に従いリンクを作る
   - PC: **アフィリエイトツールバー**
   - スマホ/補助: **商品リンク作成**
   - バナー・キーワードリンクは必要に応じて
7. 報酬受取（口座 or DMMポイント）設定を確認（支払下限あり: 公式ヘルプ参照）

### Done when

- [ ] アフィリエイト管理画面にログインできる
- [ ] サイトが承認済み
- [ ] 紹介したい商品のアフィリンクを1本以上コピーできている
- [ ] 記事内 `{{AFFILIATE_LINK}}` を実リンクに置換した

公式:

- https://affiliate.dmm.com/
- https://affiliate.dmm.com/guide/diagram
- https://affiliate.dmm.com/guide/diagram/toolbar
- https://affiliate.dmm.com/guide/diagram/ad
- https://support.dmm.com/affiliate

## STEP 5 — 稼ぎ直結構造の完成（内部導線）

### やること

1. サイト内リンクを繋ぐ
   ```
   トップ or 固定ページ
     → ハブ記事（比較/ガイド）
       → レビューA / レビューB
         → 各CTA（アフィリンク）
   ```
2. ハブ記事では **1本推し** を明確にする（3選紹介でも結論は1つ）
3. 全記事で CTA 配置を `docs/04_text_click_methods.md` に合わせて点検
4. フッター or サイドに常設「おすすめはこの1本」

### Done when

- [ ] ハブから全レビューへ内部リンクがある
- [ ] レビューからハブへ戻るリンクがある
- [ ] 全公開記事で CTA が3箇所ある
- [ ] 推し商品が記事を読まなくても分かる

---

## STEP 6 — 文章で踏ませる / 動画・SNSで踏ませる

### やること

1. 文章: `docs/04_text_click_methods.md` の文言パターンを記事に適用
2. SNS: `docs/05_video_sns_click_methods.md` と `templates/x_post_templates.md` で入口投稿を作る
   - 基本導線: **投稿 → プロフィール or 中間記事 → アフィリンク**
   - 直貼り連投はプラットフォーム規約リスクが高い
3. 動画を使う場合
   - 概要欄/固定コメント/説明文に **中間ページURL**
   - 動画内で「詳細は概要欄」と口頭/テロップ
4. 初週の投稿本数を決める（例: X 1日1〜3本、ブログ週2本）

### Done when

- [ ] X プロフィールに中間ページURLがある
- [ ] 入口投稿テンプレを3本以上ストックした
- [ ] 動画を使うなら概要欄導線が書けている
- [ ] 「直リンク連投しない」ルールを自分用にメモした

---

## STEP 7 — 公開・計測・改善

### やること

1. 記事を最終公開し、スマホ表示で CTA が押せるか確認
2. DMMアフィリエイト管理画面のレポートでクリック/成果を見る習慣をつける
3. 週1で改善する順番
   1. クリックがゼロ → 入口（タイトル・投稿・検索キーワード）を直す
   2. クリックあるが成果ゼロ → CTA文言・推しの明確さ・商品選定を直す
   3. 成果あり → 同型記事を量産
4. `checklists/first_campaign.md` を最終チェック

### Done when

- [ ] 初回キャンペーン3記事が公開済み
- [ ] 実アフィリンクが動作確認済み（自分で踏んで商品ページに着地）
- [ ] レポートの見方を1回確認した
- [ ] 翌週の改善テーマを1つ書いた

## 完了定義（キット利用のゴール）

次をすべて満たしたら「環境が整い、初回キャンペーンを回せている」状態です。

1. ニッチ1 + キーワード3 が文書化されている
2. 媒体（ブログ等）が公開され、記事3本以上
3. DMMアフィリエイト承認済みで実リンク設置済み
4. 文章CTAと SNS/動画入口の両方の型がある
5. `python scripts/check_kit.py` が pass する（キット欠損なし）
